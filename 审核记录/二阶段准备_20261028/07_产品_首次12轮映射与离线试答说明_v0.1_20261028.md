## 3. 拒答、记不清与来源继承

本节区分内容层面的语义目的；最终导出字段及正式关闭算法由技术审查后定稿。不得在“新题本”名义下放宽 D0 05-08 的禁问范围。

| 情况 | 内容侧处理 | 后续允许什么 |
|---|---|---|
| 没展示某个 A 槽位或日期卡 | 无回答、无证据、无拒答；记未展示原因 | 可按其他独立目的继续，不能说参与者拒绝 |
| 展示后空白离开 | 记已展示未作答，不推断动机 | 不造证据、不自动关闭全部领域；受疲劳与结束控制约束 |
| 明确“不想回答” | 关闭当前请求目的；明确拒绝整事件/整域时按更大范围关闭 | 其他既有合法资料保留；不换编号、换措辞或转问伴侣 |
| 记不清且无正文 | 记录 closed_unknown，关闭相应目的 | 不把记不清当拒答；日期不清只关 date |
| 记不清但有正文 | 保留正文并逐项标注，按 D-12、D-56、D-59 检查控制 | 不能因按钮就丢掉可用内容，也不能一律关闭所有目的 |
| “最近没有” | 有效无事件自述，不建虚构事件 | 跳过该事件日期与依赖它的补问；不自动关闭所有关系话题 |
| “目前没感到变化” | 有效 change_none 候选 | 不追问不存在的之前/之后变化链 |
| 本人主动补充 | 接收并按实际来源、权限复核 | 不清除拒答记录，不自动重启已关闭主动追问 |
| 主答权限收紧/撤回/修订 | 补问继承更严限制；撤回联动失效；修订后核对是否仍指原目标 | 重算派生内容，不能靠新增回答行重置权限 |

补问拒绝某一要素时，只关闭其真正请求的那一项；若当前正式结构不能表达该粒度，应先使用更保守的关闭范围，不能为多问而少关。期待/变化的细分关闭尤其需要技术明确，不把“再换一种说法”当新目的。

F02/F04 没建出事件时的拒答，涉及现行 D-36 的 D4 domain_content 默认关闭。技术未确认新映射前，沿用保守范围；若后一道固定事件题可能触及已关闭的事，应抑制。不能为了保留七个固定槽位而绕过关闭；“最近没有”则不同于明确拒绝。

不同题所指是否同一事件尚未判清时，保守阻止可能重复的目的；身份判断不能读取伴侣答案来影响首次选题。正式双人阶段的拒答传播规则仍保留，本稿不取消它；相关控制与首次本人选题独立性的关系由技术在新增映射中明确。

## 5. C03 的比较路径与同情境工作定义

### 5.1 先区分三种东西

- **同一领域：** 例如都涉及被理解与回应。只是粗粒度内容分类，不证明可比，也不证明同一事件。
- **同一非事件情境：** 在同一领域中，双方独立回答实际指向可共同界定的关系事项或互动情境，能说明正在比较怎样的本人体验；不要求同一天或同一具体事件。应核对互动事项、各自角色及适用条件是否可比，不将措辞相似当充分依据。
- **同一具体事件：** 需要按 SPEC 6.7 独立锚点与复核确认。共同提示窗口不算锚点；具体日可以是关键锚点，周不可以；经复核的独特顺序也可成为关键锚点。

上述“核对事项、角色、条件”是帮助评审者解释现有可比性含义的观察维度，**不是新增必须齐全的数据库字段或硬门槛**。含糊时保留未知，由龚老师和产品核对；技术只读 context_group 相等，不能靠它代替语义判断。

### 5.2 非事件体验比较如何成立

沿用现有定义：双方各有同领域的清楚本人体验，标在同一经语义复核的 context_group，或挂在同一已确认配对下，并满足当前查看者可用性和许可要求。J013 只让团队内部多一种可分析的来源范围，不会自动让用户视角有同样结果。

体验的正负或期待不同可以并列，不因此自动成为事实冲突。meta、仅话题、动作片段或量表覆盖，不能自动替代本人清楚体验。

context_group 不是题号，也不是模板号；两人回答 F04 或 T02 不代表同情境。content_group 用于同一期待/变化的材料合并，与 context_group 不可互换。

### 5.3 未确认、不同与信息不足

事件配对确认仍须至少两个锚点、至少一个关键锚点、无不相合锚点、无多候选身份歧义并已复核；一个同日日期不足以单独确认。共同片段还须双方支持至少两个相合的动作步骤及先后，不能把事件确认直接写成共同过程成立。

语义复核可以在本轮审阅记录中区分“有理由同组”“明确不同”“信息不足”。这是内容审核备注，不是给正式工作簿或数据库新增状态字段；当前不同和不足都可表现为无共同分组，保留待定，不擅自改结构。

判例先用于检验这些定义能否被一致理解，不回填七对历史 context_group，不把历史未知改为不同或相同。

## 6. 首批最小合成判例（6 个，均待龚老师审核）

以下为本次设计的虚构资料，不来自七对参与者，不是已经人工验证的 gold 标签。

| 编号 | A、B 的合成材料概要 | 候选判读 | 要检查的误判 |
|---|---|---|---|
| T-C01 | A：下班想聊工作烦心事时，通常感到被认真听见。B：自己下班想聊工作烦心事时，常有没说完的憋闷感。 | 可以研究同一类情境的体验并列，不要求是同一天；需确认两人所指互动类型确实可比 | 感受不同被当成事实矛盾；没有同一事件就拒绝一切比较 |
| T-C02 | A：向 TA 讲工作烦心事时感到被理解。B：家人生病时 TA 帮忙安排照顾，自己感到被支持。 | 同域但现有描述指向不同情境，不自动共组 | 都是“支持”就给同一 context_group |
| T-C03 | A：需要商量共同安排时常感到被尊重。B：只写“还行”。 | 信息不足；不能判定同组，也不能断言明确不同 | 把短句强行补成体验，或把未知写成不同 |
| T-C04 | 双方回答同一个“交流”题，但 A 在说出游安排，B 在说自己寻求情绪回应 | 同一道题不构成共同情境；需看实际对象与角色 | 用题号直接填 context_group |
| T-C05 | 双方只给同一周和相同系统窗口，没有独立具体日或独特顺序 | 不能因窗口/周一致达到事件确认；保留待定 | week 被当关键锚点；提示日期被计成个人证据 |
| T-C06 | 双方独立给出同一具体日，但其他信息只有泛泛“聊了聊”，无法消除事件歧义 | 同日不是单独确认的充分条件；需要其他合格锚点和复核 | 只要同日就配成共同事件，进一步补造共同过程 |

评审顺序：先分别给出判读及依据，再对照差异；有分歧先修改定义或表达，不为了让答案一致而把模糊材料补成清楚。六例只是覆盖定义边界的最小候选范围，不承诺足以验证整套比较规则。

## 7. 离线试答怎样执行

### 7.1 先审核，再安排 8—10 人试答

本次交付只完成草稿，不声称已邀请、已试答或已通过。先由产品审阅，再交龚老师检查语义、角色、回指、证据与控制可标注性；处理关键问题后，使用同一冻结版本开展 8—10 **名**目标用户试答。

若要观察独立双方材料的可比性，可优先考虑 4—5 对各自作答；这只是组织建议，不把 8—10 人改为 8—10 对。若实际只获得个体样本，照常观察理解和本人信息，不据此宣称验证了双人比较。

参与者各自作答、不相互看答案。主持人不能根据另一方答案补题、提示角色或选事件，不能为补齐本轮目标临时加第 13 轮。

### 7.2 主流程与访谈分开

主流程按 06 号的固定槽位与本人候选规则执行；未实现的自适应由主持人按预先审查的本人规则卡模拟，并标明“人工模拟”。每次展示必须记录触发依据，不能边看伴侣材料边临时决定。

结束说明的理解测试使用**预设虚构状态卡**。须告诉参与者是在试读一段示例说明，不把卡片写成对这对情侣真实交付状态的判断，也不读取伴侣缺口来决定试答者应收到哪一张卡。

主流程结束后，如参与者愿意且不疲劳，可另外安排题意访谈，记录为研究环节并独立计时；不将访谈中的新关系内容混回主流程，不能借“不计轮数”延长产品采集。重点问题包括：

- 对 F01：这题希望你提供什么，是否误以为要解释分数？
- 对 T02：题里是谁需要被理解、是谁的感受？
- 对 F02/F04：你会怎样判断“小事”“认真聊”和“最近没有”？
- 对 F03/F05：具体日和周如何选择，记不清日期是否会让你误以为其他答案无效？
- 对 F07：你写的是自己的猜测，还是 TA 真正讲过的内容？
- 对两种结束说明：你理解下一步可以做什么，是否感到被归责或被迫继续？

不增加保密理解专项访谈，不要求参与者为获得更好结果取消保密。

### 7.3 时间与早停

正常主流程以每人最多 12 轮为上限，而非完成目标。记录主动用时和系统等待，沿用 D1 Q05 的内测起点：

| 触发 | 本轮要求 |
|---|---|
| 主动用时超过 32 分钟 | 该段只保留仍适用的固定题，不再展示自适应 |
| 主动用时超过 38 分钟 | 跳过该段剩余追问 |
| 达到 45 分钟 | 停止继续采集 |
| 本人疲劳、主动结束或连续两次明确跳过 | 停止继续追问并给结束入口，不以时间还没到为由追加 |
| 安全或退出控制 | 按既定中性停止，不自动恢复 |

量表和其他产品采集占用的主动用时不能在进入追问段时清零。离线仅试题意、没有施测量表时，如实记“内容试答用时”，不能据此宣布正式 57 次评分加追问全程已达到 30 分钟目标。

### 7.4 空白记录表

受控记录每个实际展示轮次至少包括：

| 记录项 | 说明 |
|---|---|
| 参与者代号、题本版本、段落、展示序号 | 不用身份信息作分析主键 |
| F/A 槽位、实际 T 模板及目标 | 分清五个自适应位置与实际问句 |
| 为什么可问、来源属于谁、缺什么 | 证明本人触发、一个请求，未用伴侣线索 |
| 预算、关闭状态与线索能力 | 记录未展示、拒答、记不清、未实现、预算不足等不同原因 |
| 作答状态、主动用时、跳过及结束位置 | 不从字数或速度推断不配合 |
| 题意与角色是否理解 | 非预期回答不自动等于理解错误，记录依据 |
| 信息是否形成清楚体验/具体行为/事件线索 | 分别判断，长回答不等于高质量 |
| 模板忠实性及来源归属 | meta 不变 TA 事实；本人观察不变 TA 本人体验 |
| 可比对象/情境是否可核对、复核分歧 | 与最终共同交付程度分开 |
| 修改建议和责任角色 | 明确改文字、改规则映射或暂缓 |

本轮公开仓库只放空白表、汇总与裁决，不写单个人的保密勾选、原始回答或细节。语义判读由龚老师复核、产品处理产品取舍；不由自动标注直接代签。

报告按适用题数给出计数和分母：实际展示、实际回答、清楚本人体验候选及复核通过、角色理解偏离、可核对情境、跳过、结束和主动用时。样本小不设虚构提升率或达标百分比；答完、认同与共同交付分别报告。
