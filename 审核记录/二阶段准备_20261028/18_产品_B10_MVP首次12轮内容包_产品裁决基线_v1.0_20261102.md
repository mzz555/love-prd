## 1. 本版所要证明的产品价值与 MVP 范围

通过三套量表、七固定题与**最多**五个自适应槽位，获得 A、B 各自的清楚本人资料，支持后续有依据的双人建模与比较。首次选题**只读本人有资格使用的材料**，不得借用伴侣进度、回答、保密推断、internal 结果、B06 假设或未批准的量表分数触发。不能取得清楚信息时保留“未知/不足”，不能强问补齐。

本版 P0：冻结可显示的题干与必要按钮、实际轮次和缺口选题边界、拒答及权限、不误导的结束反馈、展示记录。P1/后接：B09 的人工语义参照与正式语义验收、B08 的具体真人模式准入；B06/B07 与完整量表分数触发不阻挡首次追问核心开发。T07 的后续再评估、第二次同目标补问、动态评分排名、完整自动计时与复杂用户提示均不纳入本期 MVP。

**不增加第十三轮；无需问满十二轮；不为了表格齐全而追加追问。**

## 2. Q01｜六维内部工作名与用户显示词

六维依旧是已有 D1—D6 产品分类，不冒充已经独立验证的六项心理测量构念。**内部工作名采用英文**，仅用于协作与说明；内部代码、已有字段、D1—D6 编号不因翻译而改名。用户端默认不显示内部分类，确有必要提示时使用经过审核、自然的中文，不强制显示英文。

| 内部编号 | 内部英文工作名（产品确认） | 中文理解用名 |
|---|---|---|
| D1 | Closeness & Reliance | 亲近与依靠（原“亲近与依赖”的含义范围保留） |
| D2 | Perceived Understanding & Responsiveness | 感受到的理解与回应 |
| D3 | Needs & Expectations | 需要与期待 |
| D4 | Interaction & Repair | 互动与修复 |
| D5 | Overall Relationship Experience | 关系整体感受 |
| D6 | Perceived Self-Change | 感受到的自我变化 |

题目话题名**不直接决定证据域、本人体验资格或双人同一情境**；仍按回答实际含义核验。D2/D6 的 Perceived 强调本人所述主观体验，不禁止正确记录实际观察到的行为，也不构成对伴侣事实或因果的直接证明。

**本版按钮与状态：**
- 普通内容题：“不想回答”“暂时说不清”；前者为明确拒答并按用户真实拒答范围关闭，后者是未知/不清楚，不等于拒答。
- F02、F04：“最近没有”；有效无事件自述，不伪造事件、不当跳过。
- F06：“目前没感到变化”；有效无变化自述，不强制讲出变化。
- F03、F05：具体日期、只能确定一周、记不清、不想回答；日期精度分开，不猜日。
- 回答控制：“这条回答不要让 TA 知道”，沿 J013/主补继承更严权限执行，不因勾选即停止内部获准分析，也不得以派生结果向伴侣泄露。
- 结束按钮统一改为 **“结束本次追问”**，其含义是停止**整个首次追问流程**，而不是只停止当前一段；不自动等于退出项目、撤回同意或删除资料。这些功能必须另按实际已支持入口与 B08 处理；未实现的功能不许在提示中承诺。
- 本文题干的可替换占位符以原始审校字面保留“{ta}”，**用户实际显示为“TA”**；技术核对现有模板引擎的占位符映射，不在界面显示花括号。

## 3. Q03｜龚老师 v0.2 正式题干基线（F01—F07）

> 本节采用审校表逐项“修改后题目/建议修改内容”；F06 以产品在 Q10 进一步确认的最终改写替换龚老师的疑问句。**题干文字是产品批准的内容基线**；不等于每一道题的触发或语义自动判定已验收。展示日期范围作为题卡的既有提示，而不把系统日期提示写入本人证据。

| 编号 | 本次批准的用户题干 | 主要采集目的与边界 |
|---|---|---|
| F01 | 最近，你对这段关系的感受是？ | 本人总体体验；“还行/还好”不自动算清楚体验 |
| F02 | 最近，你和{ta}产生分歧的事情是什么？ | 本人亲自参与的意见不同事件；不暗示一定严重争吵 |
| F03 | 刚才说的这件事，发生在什么时候？ | F02 本人事件的日期；事件不存在或目的已关则不问 |
| F04 | 最近，你和{ta}认真沟通过什么事？ | 本人参与的有来回交流；允许与 F02 为同一件事，前提和去重仍需核对 |
| F05 | 刚才说的这次沟通，发生在什么时候？ | F04 本人交流的日期；可核实已取得日期则不重复 |
| F06 | **最近，你觉得自己在这段关系中有什么变化吗？** | 本人感到的具体变化或明确没有变化；不强迫变化前后完整链 |
| F07 | 你觉得{ta}会怎么形容你们最近的相处？ | 本人对 TA 看法的**猜测（meta）**，绝不当作 TA 本人陈述 |

F02/F04 的题面从“最近一次/在共同日期范围内”改成了上述审校文字；**近 30 日、近 14 日的实际统一绝对日期窗口仍按既有规则通过题卡提示提供**，不因缩短题干而改动。技术需核对“最近一次”这个原始采集限定是否需要用户可见说明或试答观察，不能自行修改已批准题干或直接宣称等义。

## 4. Q03/Q06｜龚老师 v0.2 正式候选模板（T01—T17）

只有下表明确“可依资格进入候选”的模板才可由本期受控规则选择。每次必须先满足本人来源、唯一目标、缺口和权限，再检查预算、去重及停止。**T07 原审校题干保留供追溯，但本 MVP 禁止独立触发自动追问**；不删除编号、不暗中用它生成另一张卡。

| 编号 | 本次批准的题干 | 主要目的 | MVP 自适应资格 |
|---|---|---|---|
| T01 | 你现在对这段关系最明显的感受是什么？ | 本人总体体验 | 条件满足才可问 |
| T02 | 当你希望{ta}理解或回应时，你的感受是？ | 本人被理解/回应时的体验 | 条件满足才可问 |
| T03 | 靠近{ta}时，你的感受是？ | 本人亲近体验 | 条件满足才可问 |
| T04 | 在刚才说的那件事里，你做了什么？ | **本人行为** | 条件满足才可问 |
| T05 | 在你刚才说的那次交流中，你有什么感受？ | **本人感受** | 条件满足才可问 |
| T06 | 你觉得，刚才说的那件事为什么会发生？ | 本人所理解的起因，非客观因果证明 | 条件满足才可问 |
| T07 | 对于刚才说的那件事，你当时是什么反应？ | 本人反应；与 T04/T05 有重复风险 | **本 MVP 禁止独立自动触发** |
| T08 | 刚才说的那件事里，{ta}当时是什么反应？ | 本人所报告/观察到的 TA 反应，非 TA 自报 | 条件满足才可问 |
| T09 | 你刚才说的那件事，后来怎么样了？ | 事件结果或仍在进行 | 条件满足才可问 |
| T10 | 你刚才提到的期待，具体是什么？ | 同一期待的内容 | 条件满足才可问 |
| T11 | 你刚才提到的期待，是对谁的期待？ | 同一期待的对象 | 条件满足才可问 |
| T12 | 在什么情况下，你会有这个期待？ | 同一期待的适用条件 | 条件满足才可问 |
| T13 | 发生这个变化前，你平时是什么样的？ | 同一变化的前态 | 条件满足才可问 |
| T14 | 发生这个变化后，你现在是什么样？ | 同一变化的后态 | 条件满足才可问 |
| T15 | 你怎么看待自己的这个变化？ | 对该变化的本人评价 | 条件满足才可问 |
| T16 | 你说的“{本人用词}”，具体是什么意思？ | 本人原话的词义澄清 | 条件满足才可问 |
| T17 | 你刚才那段话，想表达的是什么意思？ | 本人原话的含义澄清 | 条件满足才可问 |

### 模板的不可逾越边界

1. 题干正文含替换后不超过 **40 字**；一张题卡只请求一项信息，辅助文字不另加隐性第二问；不输出内部编号。
2. “刚才那件事/那次交流”“这个期待”“这个变化”“刚才那段话”必须由**本人的合格原答唯一定位**。T17 若无法让用户准确知道是哪段话，就抑制，不自动拼两条引文新造问题。
3. T16 的“本人用词”只能取本人可用原文的连续 **1—8 字**，不得截断否定或限定词、引伴侣/第三人原话或从模型拼改。不能完整保留含义就不问。
4. T06 的起因归属讲述人的判断；T08 的 TA 反应归属本人观察/叙述；T07 不自动触发；F07 保持 meta。**不把观察、猜测升级为伴侣本人体验。**
5. 不能凭“同一话题/同一道题/同一天”自动确认双方事件相同或情境可比；事件身份与比较仍受原有证据门槛、权限及人工核验。
6. 若规则无法合规表达一个模板、目标不唯一、受限来源或会造成重复，**抑制出题并记录原因**，不得要求模型临时改写或者擅增 schema 枚举。
7. 六个维度、固定题、模板不因在表格中“有位置”就成为本次必问项；候选只在合法且必要时进入。

本次不启用 CSI/PRI/ECR 量表分数阈值、题对、B06 模板资料不足、internal 与伴侣进度作为首次追问触发。B02 五道禁用 CSI 题及中间变量必须隔离；允许 27 题的有效性路径只按已定限度使用，不代替清楚本人体验。

## 6. Q04/Q05/Q06｜选题、信息价值与重复控制

**Q04：同一条期待或同一项变化最多一次自适应补问（本 MVP 暂行）。** 先判断目标确实存在、能唯一定位、相关信息确实缺失，才选择一项最必要的信息；不承诺一次问完内容/对象/条件或变化前/后/评价。若仍不足，保留不足状态；**不靠新建缺口代码、换编号或多用 A 槽位来重新问同一目的**。是否允许第二次，待二阶段内测复盘后另裁决。

**Q05：必要性优先，固定顺序兜底。**
- 期待：默认 **T10 内容 → T11 对象 → T12 条件**；
- 变化：默认 **T13 前态 → T14 后态 → T15 本人评价**。
- 先去除已答清楚、目标不明、不可问或重复的选项；若有确切、可核对的业务依据认为某个缺口对当前分析更必要，允许**在该组内部**优先选择它并记录理由；不能使用大模型自定“重要性分数”、情绪强弱、回答长度或新权重来重排。
- 本规则**不改变**已有首次追问 P1—P4 全局缺口优先级及同档排序；不能凭局部顺序绕过全局资格、闭锁和预算；技术核对实际能否在现有映射表达。

**Q06：T07 本期不可独立自动触发；T04 本人行为、T05 本人感受在语义上不同。** 同一事件即使两个方面都缺，也不能因换题号绕过已关闭的实际目的或连续补问。优先遵守已定本人体验缺口优先规则以及实质目的去重。**不预先增加新的 missing/数据库字段**；若现有映射无法合法区分，先记录差异交产品核定，不能默认两问都合法。

现有其他选题底线继续有效：首次本人投影仅用本人可用来源；清楚本人体验缺口按 J014 的 P1 和 D5→D2→D1 检查；自适应已展示的同一实际目的本次不再展示；固定题必要澄清只按既有批准例外，不为修复错误加第十三轮；抽取失败不当用户无信息，不能用失败候选驱动正式结果。

## 7. Q07｜拒答、未知、结束与停止

**产品正式取消“连续两次明确跳过即自动停止全部首次追问”。** 这是对 S2-05-13、06/07 号、J020 相关后续执行口径的本期明确修改，而非仅不展示提示。取消跨段 skipped 连续计数**作为自动停止判据**；可保留跳过的真实记录用于内测复盘。

- “不想回答”按实际表达**关闭其对应目的与用户明确拒绝的范围**，不把两次局部拒答自动扩大为全局退出；不得通过重问、换域名、换模板、换后续段绕过用户真实拒绝。
- “暂时说不清/记不清”归未知；“最近没有/目前没感到变化”是有效否定自述；未展示和已展示未答分开，均不擅自记为拒答。
- 本人明确说疲劳、明确表示不愿继续、点击“结束本次追问”，或实际触发必要退出/安全停止时，仍须停止相应流程，尊重更大范围拒绝，不强求完答。
- **技术待核**：原技术回执对 F02 拒答后是否抑制 F04、结束本次追问时尚未完成量表如何运行、主补同事件身份如何自动记录，均不因本条被默示决定。与本产品原则不一致之处需提出替代方案交产品裁决。

## 8. Q08｜面向用户只保留三类必要状态反馈

原 E01—E07 的七类用户文案**不再各设一个展示步骤**。原有内部原因与状态仍准确保留，不能合并成一个数据库原因，也不能泄露伴侣状态。

| 用户看到的情况 | 本版用户文字 | 显示条件 |
|---|---|---|
| 正常完成、本人主动结束或明确疲劳结束首次追问 | **本次追问已结束，感谢你的参与。** | 追问流程确实已经结束；内部仍区别具体停止原因 |
| 系统故障导致实际无法继续 | **本次追问暂时无法继续。** | 仅真实故障阻断时显示；按实际能力给可行操作，不能承诺未实现恢复 |
| 共同分析确实已停止 | **本次共同分析已停止。** | 按实际权限与退出/安全条件显示，不暗示哪方做了什么；本期界面未接入时不为此扩建阶段四功能 |

- **取消 E01 分段结束的独立提示**：正常段间直接进入下一既定环节。
- **取消 E02 追问前说明**：合法补问直接显示问题，不额外问“愿不愿补”。
- E03、E04、E05 **使用同一结束文案**；E05 不再由连续两次跳过触发。
- E06 抽取失败但后续固定题可继续时**不报系统故障、不中止整个流程**；故障确实阻断时才按第二类处理。
- E07 按真实停止状态反馈，不泄露来源；不把“回答完”写作分析已完成，也不承诺无法实现的“查看/更正”操作。
- 不新增确认页、无意义的弹窗、额外题卡或复杂导航。

## 9. Q09｜本阶段不做主动计时和 32／38／45 自动门槛
