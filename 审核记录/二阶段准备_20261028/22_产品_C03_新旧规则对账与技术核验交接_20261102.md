## 二、继续有效的强制规则

1. **S2-04-19/20/21/22/23/24** 的本人体验有效性、事件配对、共同片段、非事件比较、证据/状态、阅读者权限及单方/双方信息边界全部继续有效；不使模型拥有事实仲裁权。
2. 经核准的**context_group** 和可见可用的各自清楚本人体验是非事件情境双人比较的依据；无有效语义核验而仅“两个 group 值一样”不是充分的正确性证明。**content_group** 和相同题号/模板号不能替代它。
3. “同一领域可并列”只意味着陈述双方**分别**涉及的领域，不允许在不满足情境比较资格时写成两人在相同情境下的体验有差异或冲突。
4. 语义审核的“有理由同组/明确不同/信息不足”是**人工审核用的判断语言**，不是本次新数据库枚举。尤其 T-C02 的具体事项不同、T-C04 的证据不足须区分，不能把“无共同分组”统一回译成“明确不同”。
5. 事件日期精度、独立锚点、多个候选身份、冲突与复核依既定 SPEC 6.7，禁止静默降级或升级；**事件已确认不代表双方完整叙述或共同过程成立**。
6. J013 的 A/B/internal 可用范围、来源权限、保密继承与首次追问只用本人资料继续生效；不改变七对历史数据、不对旧样本回填新的 context_group。
7. 21 号英文是**辅助完整解释**，不能直接改变中文正式业务定义；如产品日后要海外落地，另审译法/文化等价及展现。

## 三、可供技术编制的最小核验预期（全部**待执行**）

以下“预期”只作为产品级受控合成输入的设计方向，不代表已经运行模型或通过语义验收。

| 核验 ID | 输入构造 | 应成立 / 不应出现 |
|---|---|---|
| C03-K01 仅同域 | D2 主题相同但工作倾诉/生病照护不同 | 可主题并列；**不自动**共同 context_group、无同情境矛盾结论 |
| C03-K02 可比的不同体验 | T-C01 模拟条件明确与条件不充分两份变体 | 已独立核查相同倾诉情境与本人体验时，允许有条件同情境比较；不足时保留未知；不凭感受正负判事实矛盾 |
| C03-K03 模糊体验 | T-C03 “还行”，改变 A 的说法作控制 | 保留 B 原句，无凭空补全，不因 A 变化推定 B；合法澄清可选，不产生强制额外追问 |
| C03-K04 同题不同事项 | T-C04 同一道交流题，A 出游安排/B 情绪回应；给出/撤去有据的新信息 | 仅同题不能生成 context_group；未证实不同事件时保留待定；后续证据可以重新核查 |
| C03-K05 周/窗口 | T-C05 只有同周、同系统日期范围 | 不生成已确认事件，不计系统窗口为个人证据，不推算具体日 |
| C03-K06 同具体日不足 | T-C06 同日+“聊了聊”，无第二锚点/有多个同日候选 | 日期最多为一合格关键锚点，不通过事件确认，无共同过程 |
| C03-K07 事件成立正例与反例 | 两独立相合锚点（至少一关键），有/无未解决身份冲突或多候选歧义；双人动作证据独立控制 | 全部事件条件满足且经复核才确认；共同过程仍单独检查；不合格反例不得通过 |
| C03-K08 角色不相同 | 合法合成的照顾者/被照顾者体验，分别有/无清楚比较角度 | 不机械要求同角色，但不能混写角色、把本人猜 TA 当 TA 事实 |
| C03-K09 权限隔离 | 可见/保密、受控 internal、A/B 视角变化，重放合成资料 | 当前视角只用合法可用证据；不能因 internal 允许多看到而泄露给另一方，首次追问不偷读伴侣 |
| C03-K10 真实状态对账 | 比较当前代码实现与 21 号语义，以及 08 号相关 S2 规则 | 必须列出实现/待做/需产品裁决与实际日志；不得在未验证时写“已通过” |

以上只核业务规则。**模型自动抽取、语义复核准确性、语义参照集的可靠性、真实使用效果及运行回归**需要按对应 B03/B09/B08/B10 流程**另外执行**；测试期望已确定不等于模型会正确执行它。
